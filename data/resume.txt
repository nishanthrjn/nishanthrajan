## AI Projects

### TalentBot
AI-powered portfolio chatbot. Recruiters can have a real conversation with an AI grounded in my 16+ years of engineering experience. Built with Python, FastAPI, LangChain, FAISS, HuggingFace embeddings, and Groq Llama 3. Uses semantic chunking and cosine similarity search for accurate, grounded answers.

### DocuMind
NotebookLM-inspired document intelligence platform built in C#/.NET 10. Upload PDFs, chat with them using AI, and get answers with inline numbered citations showing the exact source text. Features: pgvector similarity search, Groq for fast responses, Blazor Server UI with conversation history, time-based themes, citation popups, and markdown export.

### NexusAI
Multi-agent orchestration platform built in C#/.NET 10 with Microsoft Semantic Kernel. Five specialist agents — Coordinator, WebSearch, Document, Analysis, and Report — collaborate to answer complex research questions. Includes a Blazor live pipeline visualization, real web search via Tavily API, OpenTelemetry distributed tracing, and integration tests with Testcontainers.

### Agent-Nexus — ANAC 2026 Competition
Autonomous negotiation agent built for the Automated Negotiation Agents Competition (ANAC 2026) at IJCAI 2026. Achieved 4th place overall, competing solo as a student. Built in Python using the NegMAS framework with Bayesian opponent modeling, type-specific concession strategies, and Pareto-optimal late-game bidding.

### AutoFlow
IoT workflow automation platform with MQTT messaging. Built in C#/.NET.

### JobRadar
Multi-source job aggregator built in Python. Aggregates job listings from multiple sources automatically.
