# Reference-only files

These files are comprehensive human/application-generation references.

DO NOT INDEX THIS FOLDER INTO TALENTBOT.

Why:
- They intentionally repeat facts across CV, project, skills, FAQ, and profile sections.
- Duplicate evidence can dominate semantic retrieval.
- General skills and adjacent project descriptions can be incorrectly merged by an LLM.

Use the sibling `../ingest/` folder as the TalentBot vector-store source.
